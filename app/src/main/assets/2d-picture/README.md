# 2D Picture Assets for Monitor Screen

This folder stores 2D pictures of lettuce varieties across their 4 growth stages, used for display on the monitor screen cards.

## Naming Convention
- `{variety}_{stage}.jpg` (or `.png`)

### Stages:
1. `seedling`
2. `vegetative`
3. `heading`
4. `maturity`

### Varieties:
- `olmetie`
- `limambo`
- `orbital`
